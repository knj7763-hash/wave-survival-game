# 웨이브 서바이벌

웹 브라우저용 웨이브 서바이벌 슈팅 게임 (Phaser 3).

몰려오는 적을 자동 공격으로 버티며 스테이지 1~5를 돌파하는 로그라이트 게임입니다.
런이 끝나면 모은 코인으로 상점에서 스킬·장비·코스튬을 구매하고 다시 도전합니다.

## 조작

| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 (공격은 가장 가까운 적을 자동 조준) |
| 1 / 2 / 3 | 스킬 사용 (게이지가 가득 찼을 때) |
| F | 스킬 AUTO 모드 켜기/끄기 |
| M | 소리 켜기/끄기 |
| R | 게임 종료 후 즉시 재시작 |

## 게임 구조

- 한 스테이지 = 8웨이브 (3·5·7 준보스, 8 보스). 홀수 스테이지는 왼쪽, 짝수 스테이지는 오른쪽에서 적 등장
- 보스는 돌진 / 중앙 미사일 / 낙뢰 패턴을 쓰며, 패턴 진입 시 적 등장 방향이 바뀔 수 있음
- 레벨업 시 무기 7종(총/칼/활/너클/석궁/샷건/레이저) 중 신규 획득 또는 강화
- 코인·보스 재료·상점 구매 내역은 브라우저에 저장됨

## 개발

```bash
npm install
npm run dev      # 개발 서버 (N 키: 현재 웨이브 스킵)
npm run build    # dist/ 에 배포용 빌드
```

밸런스 수치는 `src/config.js`, `src/weapons/weaponData.js`, `src/skills/skillData.js`, `src/shop/shopData.js`에 모여 있습니다.

`main` 브랜치에 push하면 GitHub Actions가 빌드해서 GitHub Pages에 자동 배포합니다.
